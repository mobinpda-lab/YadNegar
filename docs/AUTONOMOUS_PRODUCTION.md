# YADNEGAR — Autonomous Production

## Production Flow

Issue → Branch → Code → Test → CI → PR → Review → Merge → Documentation → Next Task

## Operating Principles

- Core First Development
- Maximum Parallel Execution without conflicts
- GitHub Driven Development
- CI controlled delivery
- Continuous documentation

## Reporting

Reports must be short, non-technical, and focused on:

- Real blockers
- Important decisions
- Required human intervention

## Release Goal

Release Candidate with stable Core, green CI, complete documentation, and repeatable delivery process.
